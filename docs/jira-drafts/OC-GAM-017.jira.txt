h3. Description
In *Manage games*, the Game search treats {{%}} as "match anything" instead of as a plain character. Searching {{%}} lists *every game*, although no game name contains {{%}}. The page sends the character correctly encoded ({{game_name=%25}}), so the server itself interprets it. That usually means the value goes into a SQL {{LIKE}} pattern without its wildcard characters escaped, and {{_}} would likely behave the same way (matching any single character).

*Found by:* Admin_weibo automation - OtherCategoryManageGamesSuite, run 2026-09-29 14:41 (GMT+7)

h3. Suggested fix
Escape {{%}}, {{_}} and {{\}} in {{game_name}} before building the {{LIKE}} pattern (or use the ORM's literal-contains helper).
