h3. Description
On *Product > Other Category > Manage games*, searching for a game that doesn't exist makes the table header break. With the body showing only "No data", the *Game* column collapses to zero width. Its header disappears, and the header bar covers only part of the table's width, while "No data" spans all of it.

*Found by:* Admin_weibo automation - OtherCategoryManageGamesSuite, run 2026-09-29 14:41 (GMT+7)
*Test case:* OC-GAM-011

h3. Steps to reproduce
# Sign in to https://admin-test.1083.city/ as qa0001, with currency HKD.
# Open *Product > Other Category* and click *Manage games* on any category (e.g. "QA OC Popular Games").
# In *Game*, type {{sss}} and press Enter.

h3. Expected result
The empty table still shows every column header - *Selected | Game | Provider | Game banner | Action* - each on one line across the full table width, with "No data" below.

* The header shows *Selected | Provider | Game banner | Action*. The *Game* header is squeezed to nothing (automation measured "Game: cut off").
* The header bar ends partway across, while the "No data" row spans the full width.
* The search request itself is fine: {{GET /api/account/game?paginate=20&page=1&game_name=sss&currency=HKD}} returns 200 with no games.
